# Отчёты по шагам

Каждый шаг — файл `reports/step-NN.md`. Секреты, содержимое `.env`, пароли и ключи API в отчёт не попадают.

## Шаблон

```markdown
# Шаг NN. Название

## Что сделано

## Изменённые файлы

## Выполненные команды

## Результаты проверок

## Проблемы

## Что нужно от тестера
```

- **Что сделано** — по задачам шага из [docs/03-roadmap.md](../docs/03-roadmap.md).
- **Изменённые файлы** — пути относительно корня репозитория.
- **Выполненные команды** — команды, которые реально запускались, без секретов в аргументах.
- **Результаты проверок** — что смотрели и чем закончилось.
- **Проблемы** — расхождения с ТЗ и блокеры.
- **Что нужно от тестера** — что проверить в git или на сервере.
